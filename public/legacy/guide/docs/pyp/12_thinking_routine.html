단원 진행 중 · 양식 12 PYP

생각하는 루틴 🧠

See–Think–Wonder Routine
언제 작성하나요
사진·영상·작품·실험·실제 사물을 봤을 때.
왜 작성하나요
눈으로 본 것에서 시작해 깊은 생각으로 가는 사고법이에요.
See–Think–Wonder는 PYP에서 가장 자주 쓰이는 생각 루틴이에요. 그림, 사진, 실험, 책 표지 등 무엇이든 "보이는 것 → 생각되는 것 → 궁금해지는 것" 순서로 차근차근 살펴봐요. 똑같은 것을 봐도 더 깊게 보이게 돼요.
사진·실물·영상·책 등 무엇이든 됩니다.
👀
보여요
See — 눈에 보이는 것
단순한 사실만 적어요. "나는 ____을 봐요."
💭
생각돼요
Think — 내 머리로 생각한 것
왜 그런 것 같은지 생각해요. "나는 ____라고 생각해요."
❓
궁금해요
Wonder — 알고 싶어진 것
이걸 보고 생긴 질문이에요. "나는 ____이 궁금해요."
학부모용 메모. See–Think–Wonder는 가정에서도 매우 잘 활용돼요. 박물관·미술관에 갔을 때 그림 앞에서 자녀에게 "보여? → 생각돼? → 궁금해?" 순서로 물어보세요. 단순히 "예쁘다"가 아닌, 진짜로 작품을 깊이 보는 방법을 자녀가 배우게 됩니다. 가장 어려운 건 "본 것"과 "생각한 것"을 구분하는 거예요. 자녀가 헷갈리면 "그건 봤어, 생각이야?"라고 다시 물어봐주세요.
