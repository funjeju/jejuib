학기 말 · 양식 23 PYP

학생 주도 컨퍼런스 대본 🎤

Student-Led Conference Script
언제 작성하나요
학기 말 학부모 컨퍼런스 1~2주 전.
왜 작성하나요
학부모님께 내 학습을 직접 발표하는 대본이에요.
학생 주도 컨퍼런스(SLC)는 PYP의 특별한 자리예요. 일반 학부모 상담과 달리, 학생이 학부모님께 직접 발표해요. 내 학습을 내 말로 설명하는 것 자체가 큰 학습이에요. 아래는 대본 안내예요. 천천히 채워보세요.
1
👋 시작 인사
1분
예시 문장: "안녕하세요. 오늘은 제가 이번 학기 어떻게 배우고 자랐는지 직접 보여드릴게요. 시작해도 될까요?"
2
⭐ 가장 자랑하고 싶은 작품 한 가지
3~4분
설명할 것: 어떤 단원이었나 / 무엇을 만들었나 / 어떻게 만들었나 / 무엇을 배웠나
3
🌱 한 학기 동안 자란 모습
2분
설명할 것: 학습자상 자질 중 자란 것 / 학습 근육 중 키운 것 / 어떻게 알 수 있나
4
💪 어려웠지만 극복한 것
1~2분
설명할 것: 어떤 어려움 / 어떻게 해결 / 무엇을 배움
5
🎯 다음 학기 약속
1분
설명할 것: 더 잘하고 싶은 한 가지 / 어떻게 해볼 건지
6
💝 마무리 + 가족에게
1분
설명할 것: 도움 받고 싶은 것 / 가족에게 고마운 점 / 질문 받기
💡 발표 잘하는 팁
  • 천천히, 또박또박 말하기
  • 가족 얼굴을 보면서 말하기
  • 중간중간 작품을 보여주기
  • 실수해도 괜찮아요. 다시 말하면 돼요
  • 마지막엔 "질문 있으세요?" 묻기
학부모용 메모. SLC는 자녀가 학교에서 처음 경험하는 "발표자" 역할이에요. 한국 학교에서 잘 운영되지 않더라도, 가정에서 학기 말마다 이 자리를 만들어보세요. 가족 앞에서 자녀가 자기 학습을 설명하면, 자기 인식이 깊어지고 표현력이 자랍니다. 발표 중 자녀를 비판하지 말고 "잘 설명해줘서 고마워"가 가장 좋은 반응이에요.
