# Legacy Build Scripts (보관 전용)

⚠️ **이 폴더의 스크립트는 더 이상 실행하지 않습니다.**

과거 정적 IB 학부모 가이드 사이트를 빌드하기 위해 사용되던 Node.js 스크립트들입니다.

새로운 펀제주 플랫폼은 Next.js + Firebase로 마이그레이션되었으며, 기존 가이드 사이트는 `/public/legacy/guide/` 에서 정적으로 서빙됩니다.

## 스크립트 목록

- `update.js` - 메인 페이지 CSS/JS 주입
- `glossary_ui.js` - 용어 검색 UI
- `glossary_data.js` - 용어 데이터
- `make_portal.js` - 포털 자동 생성
- `add_glossary.js` - 기존 HTML에 용어 추가
- `generalize.js` - 일반화 처리
- `split_site.js` - MYP/PYP 사이트 분할
- `init_pyp.js` - PYP 초기화
- `update_pyp_*.js` - PYP 콘텐츠 업데이트
- `seo_and_ib_intro.js` - SEO 메타데이터
- `blog_seo.js` - 블로그 SEO
- `fix_pyp_nav.js` - PYP 네비게이션 수정
- `update_pyp_parent_forms.js` - PYP 학부모 양식 업데이트

## 참고

과거 가이드 콘텐츠 수정이 필요한 경우는 별도로 상담하세요.
